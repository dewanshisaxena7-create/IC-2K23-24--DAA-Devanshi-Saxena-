# Algorithm Performance Analyzer

## Problem Statement

Develop an Algorithm Performance Analyzer to compare the theoretical and experimental performance of Iterative and Recursive Binary Search.

## Algorithms

- Iterative Binary Search
- Recursive Binary Search

## Complexity Analysis

| Algorithm | Best Case | Average Case | Worst Case | Space |
|---|---|---|---|---|
| Iterative Binary Search | O(1) | O(log n) | O(log n) | O(1) |
| Recursive Binary Search | O(1) | O(log n) | O(log n) | O(log n) |

## Experimental Analysis

The algorithms are tested using different input sizes and their execution times are measured.

The experimental results are stored in `results.csv`.

## Performance Graph

The execution-time comparison is represented using `performance_graph.png`.

## Learning Outcomes

- Understand iterative and recursive Binary Search.
- Analyze theoretical time and space complexity.
- Measure experimental execution time.
- Compare theoretical and experimental performance.
- Store results in CSV format.
- Generate performance graphs.
