DAA-ALGORITHM-PERFORMANCE-ANALYZER
1. Problem Statement
Develop an Algorithm Performance Analyzer to compare the theoretical and experimental complexity of algorithms.

The analyzer measures execution time for different input sizes, stores the experimental results in a CSV file, and generates performance graphs.

This project compares Iterative Binary Search and Recursive Binary Search.

2. Algorithm / Approach
Iterative Binary Search
Binary search is performed iteratively by repeatedly dividing the sorted array into two halves until the target element is found or the search range becomes empty.

Recursive Binary Search
Binary search is performed recursively by dividing the search range into two halves and recursively searching the appropriate half.

Performance Analysis
The program:

Generates sorted arrays of different input sizes.
Selects a target element from the array.
Measures the execution time of both binary search implementations.
Stores the results in results.csv.
Generates a performance comparison graph in performance_graph.png.
3. Pseudocode / Flowchart
Iterative Binary Search
BinarySearchIterative(A, target)

low = 0
high = length(A) - 1

while low <= high

    mid = (low + high) / 2

    if A[mid] == target
        return mid

    else if A[mid] < target
        low = mid + 1

    else
        high = mid - 1

return -1
Recursive Binary Search
BinarySearchRecursive(A, low, high, target)

if low > high
    return -1

mid = (low + high) / 2

if A[mid] == target
    return mid

else if A[mid] < target
    return BinarySearchRecursive(A, mid + 1, high, target)

else
    return BinarySearchRecursive(A, low, mid - 1, target)
4. Time & Space Complexity Analysis
Algorithm	Best Case	Average Case	Worst Case	Space Complexity
Iterative Binary Search	O(1)	O(log n)	O(log n)	O(1)
Recursive Binary Search	O(1)	O(log n)	O(log n)	O(log n)
